Learning Objectives

When you finish this module, you will be able to:

  1. Calculate the subnet mask that provides a required number of assignable hosts
  2. Apply the “hosts + 2” rule and powers of 2 to size a subnet
  3. Construct a network address table: network, usable range, and broadcast for each subnet
  4. Determine whether two hosts are on the same subnet

Subnetting for a Number of Hosts

This is the question you will answer most often on the job: “I need room for this many devices per network. What mask do I use?” The answer comes from one idea: a subnet must hold every host plus two reserved addresses, and subnet sizes only come in powers of 2.

Technical Overview

Classless Inter-Domain Routing (CIDR) lets the mask fall on any bit, not just octet boundaries. To size a subnet for H hosts, find the smallest power of 2 that is ≥ H + 2. That power, 2h, gives h host bits, and the prefix is 32 − h. Assignable hosts per subnet = 2h − 2.

In Plain Terms

Add 2 to the number of hosts you need, then count up through 1, 2, 4, 8, 16, 32, 64, 128… until you reach a number that is big enough. That number is your subnet size, and it tells you the mask.

Hosts Grow From the Right

When you solve for hosts, you count host bits from the right (least significant) end. When you solve for networks in Module 9, you count from the left. In this module’s method, each subnet is the same size; this is called fixed-length subnetting.

Example 1: 25 hosts from 192.168.1.0/24

Given 192.168.1.0/24, what mask gives at least 25 assignable hosts per subnet? Work it out, then open the solution.

Show the Worked Solution

25 hosts + 2 = 27 addresses needed. Ask the placeholder question from the right:

  1. Is 1 ≥ 27? No
  2. Is 2 ≥ 27? No
  3. Is 4 ≥ 27? No
  4. Is 8 ≥ 27? No
  5. Is 16 ≥ 27? No
  6. Is 32 ≥ 27? Yes — stop here.

On the Job

A department of 40 people, each with a laptop and a phone, needs 80 addresses plus room for printers and growth. Planning for 100 hosts gives 102 addresses, which needs a block of 128: a /25. Always size for growth, not just for today.

Where Students Trip

Forgetting the +2. If you need exactly 30 hosts, 30 + 2 = 32 fits a /27 perfectly. If you need 31 hosts, 31 + 2 = 33 no longer fits, and you must jump to a /26 with 64 addresses.

In This Module You Learned

  • Subnet size = the smallest power of 2 that is at least hosts + 2.
  • Host bits = the exponent; prefix = 32 − host bits; assignable hosts = 2h − 2.
  • Subnets are listed by adding the block size, starting from the network address.
  • The network address is the first address in each block and the broadcast address is the last.
