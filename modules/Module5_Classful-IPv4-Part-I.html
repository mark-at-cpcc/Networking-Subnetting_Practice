Learning Objectives

When you finish this module, you will be able to:

  1. Distinguish the roles of MAC (layer 2) and IP (layer 3) addresses
  2. Identify the class of any IPv4 address and its default subnet mask
  3. Classify addresses as RFC 1918 private, public, APIPA, or loopback
  4. Explain how a subnet mask separates the network portion from the host portion

Two Addresses, Two Jobs

Every device on a network carries two kinds of address. The MAC address (layer 2) gets a frame across the local network. The IP address (layer 3) gets a packet from one network to another. Subnetting is about the IP address, but you need to know where each one does its work.

Technical Overview

A switch learns the source MAC address of each incoming frame and the port it arrived on, then forwards frames by destination MAC; unknown destinations are flooded out every port except the one the frame arrived on. A router removes the layer 2 frame, reads the layer 3 packet, chooses the next hop by IP address, and builds a new frame for the next network.

In Plain Terms

The MAC address is like the name on an apartment door: it only matters inside the building. The IP address is the street address: it is what gets mail from one city to another.

IPv4 Address Structure

An IPv4 address is 32 bits, written as four 8-bit octets in dotted decimal. A subnet mask is another 32-bit number that marks which bits are network and which are host: 1s for network, 0s for host. You need both to know where a device lives.

Dotted decimalBinary
Address192.168.1.111000000.10101000.00000001.00000001
Mask255.255.255.011111111.11111111.11111111.00000000

The Mask Draws the Line

Under every 1 in the mask, the address bit belongs to the network; under every 0, it belongs to the host. With 255.255.255.0, every host on this network starts with 192.168.1, and only the last octet changes.

IPv4 Address Classes

IPv4 was originally divided into five classes based on the leading bits of the first octet. Modern networks are classless (CIDR), but the exam still expects you to identify the class and its default mask.

ClassFirst octetLeading bitsDefault maskUse
A1–1260255.0.0.0 (/8)Large networks
B128–19110255.255.0.0 (/16)Medium networks
C192–223110255.255.255.0 (/24)Small networks
D224–2391110NoneMulticast
E240–2551111NoneExperimental
Why 127 Is Missing

127.0.0.0/8 is reserved for loopback. 127.0.0.1 (localhost) always means “this device,” and it is used to test a computer’s own network stack.

Public, Private, and Special Addresses

RangeNameWhat it tells you

On the Job

A user says, “My computer has an address, but nothing works.” You run ipconfig and see 169.254.33.7. That APIPA address is your first clue: the computer never heard back from DHCP, so check the cable, the switch port, and the DHCP server before anything else.

Where Students Trip

The Class B private range is 172.16.0.0 through 172.31.255.255, not just 172.16.x.x. Addresses like 172.20.5.1 are private; 172.32.5.1 is public.

Subnet Mask Rules

A valid subnet mask is always a contiguous run of 1s starting from the left, followed by a contiguous run of 0s. You can assign hosts only within the host portion (the 0s). All 1s (255.255.255.255, /32) identifies a single host, and all 0s (0.0.0.0, /0) appears in default routes, not host networks.

In This Module You Learned

  • MAC addresses (layer 2) deliver frames locally; IP addresses (layer 3) cross networks.
  • An IPv4 address and its mask are both 32 bits; 1s in the mask mark network bits.
  • Classes A, B, and C have default masks of /8, /16, and /24; D is multicast and E is experimental.
  • RFC 1918 private ranges: 10/8, 172.16/12, and 192.168/16. APIPA is 169.254/16; loopback is 127/8.
