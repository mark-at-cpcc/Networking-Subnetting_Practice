Learning Objectives

When you finish this module, you will be able to:

  1. Explain how place value works in the decimal (base 10) and binary (base 2) number systems
  2. Convert any 8-bit binary number to decimal without a calculator
  3. Convert any decimal value from 0 to 255 to 8-bit binary using the placeholder method
  4. Explain why network addresses are written as 8-bit octets

Why This Module Comes First

Every IPv4 address and every subnet mask you will ever configure is a 32-bit binary number written in a form people can read. Routers and switches never see “192.168.1.10”; they see thirty-two 1s and 0s. Subnetting is simply the skill of reading those bits on purpose. This module gives you the one tool the rest of the site depends on: moving between decimal and binary quickly and without a calculator.

Technical Overview

A positional number system gives each digit a value based on its position. Each position is the system’s base raised to a power, starting with the power of 0 on the right. Decimal is base 10 (digits 0–9); binary is base 2 (digits 0 and 1). An IPv4 address is 32 bits divided into four 8-bit octets, and each octet holds a value from 0 to 255.

In Plain Terms

You already use place value every day: in 379, the 3 is worth 300 because of where it sits. Binary works the same way, except each place is worth twice the one to its right instead of ten times. Learn the eight place values 128, 64, 32, 16, 8, 4, 2, 1 and you can read any octet.

The Decimal Number System

Decimal uses ten digits because people learned to count on ten fingers. Each place is 10 raised to a power. You start on the right with the least significant digit and move left toward the most significant digit.

Most significant digit

The left-most digit, which carries the largest place value. In 1,000 the 1 is most significant because it sits in the thousands place.

To break a number into its parts, multiply each digit by its place value and add. For 379: (3 × 100) + (7 × 10) + (9 × 1) = 300 + 70 + 9 = 379.

The Binary Number System

A computer is built from switches that are either on or off, so it counts with two digits: 1 (on, or true) and 0 (off, or false). Each binary digit is a bit, and eight bits make a byte. In networking we call each 8-bit section of an address an octet.

Place2726252423222120
Value1286432168421

Memorize the Eight Placeholders

128, 64, 32, 16, 8, 4, 2, 1. Each is double the one to its right, and together they add up to 255. Write this row across the top of your scratch paper before every subnetting problem; on the job and on the exam, it is the fastest tool you have.

Worked Example: Binary to Decimal

Convert 10011011 to decimal. Try it on paper first, then open the solution.

Show the Worked Solution

Write the bits under the placeholders. Every 1 means “count this placeholder”; every 0 means “skip it.”

Placeholder1286432168421
Bit10011011
Bit × Placeholder12800168021

Add the counted placeholders: 128 + 16 + 8 + 2 + 1 = 155.

Worked Example: Decimal to Binary

Convert 194 to binary. The method is a series of yes-or-no questions, asked from left to right: is the number left greater than or equal to this placeholder? If yes, write a 1 and subtract. If no, write a 0 and move on.

Show the Worked Solution

Start with 194 under the 128 column and ask the question at each placeholder.

Placeholder1286432168421
Number left19466222220
Is it ≥ the placeholder?YesYesNoNoNoNoYesNo
Bit11000010

194 ≥ 128, so write 1 and subtract (66 left). 66 ≥ 64, so write 1 and subtract (2 left). 2 is less than 32, 16, 8, and 4, so those are 0. 2 ≥ 2, so write 1 (0 left), and the last bit is 0. The answer is 11000010.

On the Job

A help-desk ticket says a laptop with mask 255.255.255.192 cannot reach a printer. Converting 192 to 11000000 tells you only two bits of the last octet belong to the network, so that subnet holds just 64 addresses. You will build on exactly that reasoning in the CIDR modules.

Where Students Trip

Two habits cause most wrong answers. First, dropping leading zeros: 101 and 00000101 are the same value, but only the 8-bit form lines up with the placeholders. Second, reading from the wrong end: the left-most bit is worth 128, not 1.

In This Module You Learned

  • Every position in a number is the base raised to a power, starting with the power of 0 on the right.
  • The eight binary placeholders are 128, 64, 32, 16, 8, 4, 2, and 1, and they add up to 255.
  • Binary to decimal: add the placeholders that hold a 1.
  • Decimal to binary: ask “is the number left ≥ this placeholder?” from left to right, subtracting on every yes.
  • Always write octets with all 8 bits so the placeholders line up.
