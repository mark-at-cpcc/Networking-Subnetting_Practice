Learning Objectives

When you finish this module, you will be able to:

  1. Identify the decimal and binary value of every hex digit, 0 through F
  2. Convert two-digit hex values to binary and back by substitution
  3. Describe the structure of a 48-bit MAC address, including the OUI
  4. Distinguish a hex value from a decimal value written with the same digits

Why Hexadecimal

Long binary numbers are hard for people to read and easy to copy wrong. Hexadecimal (base 16), or hex, is shorthand for binary: every hex digit stands for exactly four bits. You will see hex in two places on the exam and on the job: MAC addresses, which you meet in this module, and IPv6 addresses, which you meet in Module 4.

Technical Overview

Hexadecimal uses sixteen characters, 0–9 and A–F, to represent the values 0 through 15. Because 24 = 16, each hex digit maps to one 4-bit group (a nibble), and two hex digits represent one byte. Conversion between hex and binary is a direct substitution, one digit at a time.

In Plain Terms

Think of hex as a code where each character replaces four bits. You never have to do long math: look up each character, write its four bits, and move to the next character.

One Hex Digit = Four Bits

Every hex digit uses the four placeholders 8, 4, 2, 1. C is 12, which is 8 + 4, so C = 1100. Two hex digits side by side are just two 4-bit groups side by side: A1 = 1010 0001.

Where Students Trip

The hex value 12 and the decimal value 12 are not the same thing. Hex 12 is 0001 0010 (decimal 18); decimal 12 is hex C. When a problem gives you a number, decide first which system it is written in.

MAC Address Format

MAC address

A 48-bit physical (layer 2) address assigned to a network interface. The first 24 bits are the Organizationally Unique Identifier (OUI) of the manufacturer; the last 24 bits identify the individual interface.

The 48 bits are written as 12 hex digits, grouped into 6 pairs and separated by colons or hyphens. Here is how one address breaks down:

PairBinaryHex
10000 000000
20101 000050
30101 011056
41100 0000C0
50000 000000
60000 100008

Written out: 00:50:56:C0:00:08. The first three pairs, 00:50:56, are the OUI.

On the Job

When a switch’s MAC address table shows an unknown device on a port, the OUI tells you who made it. Typing the first three pairs into an OUI lookup tool can tell you in seconds whether the device is a printer, a phone, or a virtual machine.

In This Module You Learned

  • Hexadecimal uses 0–9 and A–F for the values 0–15.
  • Each hex digit is exactly 4 bits, so conversion is digit-by-digit substitution.
  • A MAC address is 48 bits, written as 12 hex digits in 6 pairs.
  • The first 24 bits of a MAC address are the manufacturer’s OUI.
