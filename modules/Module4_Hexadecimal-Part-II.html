Learning Objectives

When you finish this module, you will be able to:

  1. Convert a four-digit IPv6 hextet to 16-bit binary
  2. Convert a 16-bit binary value to a hextet by grouping bits in fours
  3. Explain why IPv6 uses hexadecimal to write 128-bit addresses

From Two Hex Digits to Four

In Module 3 you converted hex two digits (one byte) at a time. IPv6 addresses use the exact same substitution, just four digits at a time. Each group of four hex digits is a hextet, and it holds 16 bits. Get comfortable here, and IPv6 addresses in Module 7 will read like ordinary numbers.

Technical Overview

An IPv6 address is 128 bits written as eight 16-bit hextets in hexadecimal, separated by colons. Each hextet is four hex digits, and each digit maps to one 4-bit group, so conversion between a hextet and binary is substitution, digit by digit.

In Plain Terms

A hextet is four Module 3 conversions in a row. Look up each character, write four bits, and keep going. Nothing new, just longer.

Worked Example: Hextets to Binary

Take the address 2201:0db8:3c4d:2012:0000:0000:1234:56ab. Convert the first hextet, 2201, and the last, 56ab.

Show the Worked Solution
HextetDigit-by-digit16-bit binary
22012 = 0010, 2 = 0010, 0 = 0000, 1 = 00010010 0010 0000 0001
56ab5 = 0101, 6 = 0110, a = 1010, b = 10110101 0110 1010 1011

Keep leading zeros in each 4-bit group, so every hextet is exactly 16 bits.

Worked Example: Binary to a Hextet

Convert 1100 1010 1011 1111 to hex. Split the bits into groups of four, find each group’s value with the placeholders 8, 4, 2, 1, and look up the hex digit.

Show the Worked Solution
GroupValueHex
11008 + 4 = 12C
10108 + 2 = 10A
10118 + 2 + 1 = 11B
11118 + 4 + 2 + 1 = 15F

The hextet is CABF.

Always Group From the Right

When a binary string is not a multiple of four bits, add zeros on the left and group from the right. 1 1011 is 0001 1011 = 1B, never 1101 1.

On the Job

Firewall logs and packet captures often show IPv6 addresses in full, while configuration screens show them compressed. Being able to read a hextet in binary is what lets you check whether two addresses fall in the same /64 network without a calculator.

Where Students Trip

Dropping the leading zeros of a group. In 0db8, the first digit is 0, which is 0000; writing only 1101 1011 1000 leaves you with 12 bits and shifts everything after it.

In This Module You Learned

  • A hextet is four hex digits, which is 16 bits.
  • Hextet-to-binary conversion is four 4-bit substitutions in a row.
  • Binary-to-hextet conversion starts by grouping the bits in fours from the right.
  • Upper- and lowercase hex letters mean the same value.
