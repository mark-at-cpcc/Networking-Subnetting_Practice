Learning Objectives

When you finish this module, you will be able to:

  1. Describe the structure of a 128-bit IPv6 address and its prefix
  2. Compress and expand IPv6 addresses correctly
  3. Identify IPv6 address types by prefix, including global unicast, unique local, link-local, and multicast
  4. Compare dual stack, tunneling, and NAT64 as IPv4/IPv6 coexistence methods

Why IPv6

IPv4’s 32 bits give about 4.3 billion addresses, and the world ran out. IPv6 uses 128 bits, enough for every device that will ever exist. The exam expects you to read IPv6 addresses, recognize their types, and know how IPv4 and IPv6 networks work together.

Technical Overview

An IPv6 address is 128 bits written as eight hextets in hexadecimal, separated by colons. A typical global unicast address uses a 48-bit global routing prefix, a 16-bit subnet ID, and a 64-bit interface ID. The prefix length (for example, /64) works exactly like CIDR in IPv4: it counts the network bits.

In Plain Terms

IPv6 is the same idea as IPv4, just much longer and written in hex. The first half says which network; the second half says which device.

Global routing prefixSubnet IDInterface ID
48 bits — assigned by the ISP16 bits — up to 65,536 subnets per site64 bits — identifies the device interface

Compressing an IPv6 Address

Two rules shorten an address without changing it. First, drop leading zeros in any hextet (0db8 becomes db8). Second, replace one run of all-zero hextets with a double colon (::), and only once per address.

Compress 2001:0db8:0000:0042:0000:8a2e:0370:7334.

Show the Worked Solution

Drop leading zeros: 2001:db8:0:42:0:8a2e:370:7334. There is no run of two or more zero hextets, and a double colon is used only to replace a run of zero hextets, so the address stays as written: 2001:db8:0:42:0:8a2e:370:7334.

Now compress 2001:0db8:0000:0000:0000:0000:0000:0001.

Show the Worked Solution

Drop leading zeros, then replace the six zero hextets with ::: 2001:db8::1.

IPv6 Address Types

IPv6 uses unicast, multicast, and anycast. There is no broadcast; the jobs IPv4 does with broadcast are done with multicast.

Link-Local Is Always There

The moment IPv6 is enabled on an interface, it creates a link-local address in FE80::/10, either from its MAC address (EUI-64, common on Cisco gear) or from a random interface ID (common on Windows, macOS, and Linux). Neighbors and routers on the same link use these addresses to find each other.

Getting IPv4 and IPv6 to Work Together

MethodHow it worksWhen you see it
Dual stackEvery device runs IPv4 and IPv6 at the same timeThe most common approach in modern networks
TunnelingIPv6 packets are carried inside IPv4 packetsCrossing an IPv4-only part of the network
NAT64A gateway translates between IPv6 and IPv4IPv6-only clients reaching IPv4-only servers
Legacy Tunneling Methods

You may see older tunneling methods in documentation: 6to4 (deprecated in 2015), Teredo, and ISATAP. All three are considered legacy and are disabled by default in current versions of Windows.

On the Job

On a dual-stack network, a firewall rule written only for IPv4 does nothing for IPv6 traffic. When you secure a network, check both protocols: an open IPv6 path is just as open as an IPv4 one.

Where Students Trip

Using :: twice. 2001::1::5 is invalid because no one can tell how many zero hextets each :: replaces.

In This Module You Learned

  • IPv6 addresses are 128 bits: eight hextets, usually split into a /64 network and a 64-bit interface ID.
  • Compress by dropping leading zeros and replacing one run of zero hextets with ::.
  • Address types: global unicast 2000::/3, unique local FC00::/7, link-local FE80::/10, multicast FF00::/8, loopback ::1.
  • IPv6 has no broadcast; multicast does that work.
  • Dual stack, tunneling, and NAT64 let IPv4 and IPv6 coexist.
