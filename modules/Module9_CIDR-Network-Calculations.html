Learning Objectives

When you finish this module, you will be able to:

  1. Calculate the subnet mask that creates a required number of subnets
  2. Choose between the hosts method and the networks method for a given scenario
  3. Construct a network address table for the first or last subnets of a range
  4. Determine the network and broadcast address of the subnet a host belongs to

Subnetting for a Number of Networks

Sometimes the question is not “how big?” but “how many?” A building has 12 floors; a company has 50 branch links. Here you borrow bits from the host portion, starting at the most significant (left-most) host bit, until you have enough networks.

Technical Overview

Borrowing n host bits creates 2n subnets. Find the smallest n where 2n ≥ the number of networks required; the new prefix is the original prefix + n. You do not add 2 when counting networks; the reserved addresses apply to hosts, not to networks.

In Plain Terms

Each bit you borrow doubles the number of networks: 1 bit makes 2, 2 bits make 4, 3 bits make 8, and so on. Keep doubling until you have enough, and count how many bits that took.

Bits borrowed12345678
Networks created248163264128256

Networks Grow From the Left

Borrowed bits come from the left side of the host portion, right after the existing network bits. The more you borrow, the more networks you get and the fewer hosts each one can hold.

Example 1: 15 subnets from 192.168.1.0/24

Given 192.168.1.0/24, what mask creates at least 15 subnets? Work it out, then open the solution.

Show the Worked Solution
  1. Borrow 1 bit: 2 networks. Is 2 ≥ 15? No
  2. Borrow 2 bits: 4 networks. Is 4 ≥ 15? No
  3. Borrow 3 bits: 8 networks. Is 8 ≥ 15? No
  4. Borrow 4 bits: 16 networks. Is 16 ≥ 15? Yes — stop here.

Borrowing 4 bits gives /24 + 4 = /28: 255.255.255.240. That creates 16 subnets of 16 addresses (14 assignable hosts each). The first three:

On the Job

A school district is connecting 35 buildings over point-to-point WAN links and was given one /24 for those links. Each link needs only 2 router addresses, so a /30 per link works: borrowing 6 bits gives 64 links, with room to add more buildings later.

Where Students Trip

Adding 2 to the number of networks. The +2 rule is for hosts only. If you need 16 networks, 4 borrowed bits (16 networks) is enough.

In This Module You Learned

  • Borrowing n host bits creates 2n subnets.
  • New prefix = original prefix + borrowed bits.
  • No +2 when counting networks; the +2 applies to hosts.
  • More networks always means fewer hosts per network.
