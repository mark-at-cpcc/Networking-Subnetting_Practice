Learning Objectives

When you finish this module, you will be able to:

  1. Apply the four binary addition rules, including adding a carried bit
  2. Add two 8-bit binary numbers and verify the result in decimal
  3. Distinguish carrying a bit in arithmetic from borrowing bits in subnetting
  4. Explain how counting up in binary reveals where one subnet ends and the next begins

Why Binary Math Matters for Subnetting

Subnetting is mostly counting. Every time you find the next network address, you are adding to a binary number and watching where the carry lands. If the carry spills into a bit that belongs to the network portion of the address, you have crossed into the next subnet. This module makes that carry automatic, so you can see it happen instead of memorizing it.

Technical Overview

Binary addition follows the same column-by-column algorithm as decimal addition, using only the digits 0 and 1. A column whose total exceeds 1 produces a carry into the next more significant place. The result of an 8-bit addition can be verified by converting the operands and the sum to decimal.

In Plain Terms

Add the way you learned in grade school: right to left, one column at a time. The only new fact is that two 1s make “10,” so you write 0 and carry 1, just like 9 + 1 makes you write 0 and carry 1 in decimal.

Carrying Is Not Borrowing

When a column overflows, the extra 1 is carried to the left. In subnetting you will also hear borrowing bits, which means something different: taking bits from the host portion of an address to create more networks. Keep the two words separate and the CIDR modules will make sense.

Two Ways to Get the Answer

Method A converts both numbers to decimal, adds, and converts back. Method B adds directly in binary. Both give the same result, because the math does not change with the base. Method B is faster once the carry is automatic, and it is the method that shows you where subnet boundaries fall.

On the Job

A network ends at 192.168.1.31, and you need the next network address. In the last octet, 00011111 + 1 carries all the way into the 32 placeholder and gives 00100000, which is 32. The next network is 192.168.1.32. That one carry is the whole idea behind the network address tables in Modules 8 through 10.

Where Students Trip

The 1 + 1 + 1 column. With two 1s plus a carry, the total is 11: write 1 and carry 1. Students often write 0 because “1 + 1 makes 0.” Slow down on any column that receives a carry.

In This Module You Learned

  • Binary addition uses the same right-to-left column method as decimal addition.
  • 1 + 1 = 10 (write 0, carry 1) and 1 + 1 + 1 = 11 (write 1, carry 1).
  • Carrying moves an overflow to the next placeholder; borrowing is a different, subnetting-only idea.
  • Checking in decimal is the fastest way to catch a mistake.
  • Counting up by one in binary shows exactly where one subnet ends and the next begins.
