Learning Objectives

When you finish this module, you will be able to:

  1. Design a VLSM addressing plan from a list of host requirements
  2. Order networks from largest to smallest to prevent overlap
  3. Calculate each network’s address, usable range, and broadcast address
  4. Justify VLSM over fixed-length subnetting for address conservation

Different Sizes for Different Needs

Real networks are not all the same size. A sales floor may need 100 addresses while the link between two routers needs 2. Variable-Length Subnet Masking (VLSM) gives each network a mask that fits it, instead of forcing every network to the size of the biggest one.

Technical Overview

VLSM applies the CIDR hosts method repeatedly within one address block, using a different prefix for each subnet. Networks are allocated from largest to smallest so each block starts on a boundary that is a multiple of its own size, which prevents overlaps. Each new network begins one address after the previous network’s broadcast address.

In Plain Terms

Pack the biggest boxes first. Sort your networks from most hosts to fewest, size each one with the hosts method from Module 8, and place each one right after the last.

A Note on Numbering

In Modules 8 and 9, every subnet is the same size, so they are numbered from Network 0. In VLSM, each network has a different size and purpose, so they are numbered Network 1, Network 2, and so on, in the order you allocate them.

Largest First, Every Time

Allocating a small network first can push a large network off its boundary. Sorting largest to smallest is the single habit that keeps a VLSM plan valid.

On the Job

A branch office has a 60-person staff LAN, a 20-device VoIP network, a 10-device management network, and two WAN links. From one /24, VLSM fits it all: a /26, a /27, a /28, and two /30s, with room left over. Without VLSM, five /26 networks would not even fit in the /24.

Where Students Trip

Starting the next network at the broadcast address. If Network 1 ends with broadcast 192.168.1.31, Network 2 starts at 192.168.1.32, not .31.

In This Module You Learned

  • VLSM gives each subnet a mask sized to its own host count.
  • Always allocate from the largest network to the smallest.
  • Each network starts one address after the previous broadcast address.
  • /30 subnets are the standard choice for two-host point-to-point links.
