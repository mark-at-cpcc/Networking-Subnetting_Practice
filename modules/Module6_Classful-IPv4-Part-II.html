Parent Networks and Subnets

A large network can be divided into smaller ones. The original block is the parent network; each piece is a subnet. Every address in a subnet keeps the parent’s network bits, so a subnet always sits inside its parent.

Technical Overview

Example: the parent network 192.168.0.0 with mask 255.255.0.0 contains the subnet 192.168.1.0 with mask 255.255.255.0. The first 24 bits of the subnet’s addresses are fixed; only the last 8 bits vary, giving the range 192.168.1.0–192.168.1.255.

In Plain Terms

Think of a parent network as a building and each subnet as a floor. Every room on the third floor shares the building’s street address and the floor number; only the room number changes.

CIDR Notation

CIDR (Classless Inter-Domain Routing, pronounced “cider”) notation writes the mask as a slash and the number of 1 bits. 255.255.255.0 is 24 ones, so it is /24.

Count the Ones

To turn any mask into a prefix, count its 1 bits. 255.255.255.192 is 8 + 8 + 8 + 2 = 26, so it is /26. Memorize the last-octet values 128, 192, 224, 240, 248, 252, 254, 255 and you can do this instantly.

Network, Broadcast, and Usable Addresses

Two addresses in every IPv4 subnet are reserved. The network address has every host bit set to 0 and names the subnet. The broadcast address has every host bit set to 1 and reaches every host on the subnet. Everything between them is usable for hosts.

On the Job

Broadcasts stop at the router. That is one of the main reasons networks are subnetted: dividing a large flat network into subnets keeps each broadcast inside a smaller group of devices, so ordinary traffic like ARP does not slow everyone down.

Where Students Trip

Calling .255 a usable host. In 192.168.1.0/24, .0 is the network address and .255 is the broadcast address, so the usable range is .1 through .254.

In This Module You Learned

  • A subnet always sits inside its parent network and keeps the parent’s network bits.
  • CIDR notation counts the 1 bits in the mask: 255.255.255.0 is /24.
  • The network address has all host bits 0; the broadcast address has all host bits 1.
  • Unicast is one-to-one, multicast is one-to-group, broadcast is one-to-all on the subnet.
