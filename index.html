Subnetting Practice Site

A CompTIA Network+ supplement: number systems, IPv4 and IPv6 addressing, and subnetting.

Site Index

How to Use This Site

Work the modules in number order; each one builds on the one before it, and the order is the method. Every module explains its idea in technical terms and in plain terms, walks through worked examples you can try before you look, and ends with a practice set you can repeat until you score a perfect set. Nothing here is graded. Every page’s Table of Contents has a Return to Site Index link back here.

Exam Objectives

This site supports CompTIA Network+ N10-009 Objective 1.7, Given a scenario, use appropriate IPv4 network addressing, and the IPv6 addressing portion of Objective 1.8, Summarize evolving use cases for modern network environments.
